# Terrain Slabs (Fabric, Minecraft 26.1.2)

Полублоки земли, травы и камня для сглаживания ландшафта.

Сборка: открыть папку в IntelliJ IDEA (Java 25), дождаться импорта Gradle,
запустить задачу `runClient` (или `gradlew build` -> jar в build/libs).

Версии лежат в gradle.properties.

## Сборка на GitHub

Залей проект в репозиторий. Вкладка Actions -> build -> Artifacts -> terrain-slabs (там jar).
Файл .github/workflows/build.yml уже в проекте.
